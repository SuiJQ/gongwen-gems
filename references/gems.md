# Gongwen Gems 句库（68 句 · v3.0 · 修辞触发器版）

本库定位是**修辞触发器**，不是成品句库。每条只提供**逻辑骨架**，禁止直接引用；必须按「三步转化法」（提实料 → 借壳 → 重组）填入用户真实信息后才可使用。

按**修辞功能**分四类 + 固定表述附录：

- **A. 破题定调型**：开篇点题、定基调
- **B. 问题剖析型**：指出矛盾、点差距
- **C. 措施执行型**：部署落实、成效印证
- **D. 收束升华型**：结尾鼓劲、表态承诺
- **附录 E. 固定表述**：法定公文格式惯例，非修辞，按规范直接使用

每条统一格式：`序号. 句子 〔类｜适用条件｜转化规则〕`，附 `✅ 正确示例` / `❌ 错误示例`。
