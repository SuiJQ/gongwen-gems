# gongwen-gems

> 🌐 项目主页：<https://suijq.github.io/gongwen-gems/>

党政公文**修辞触发器**库（OpenClaw 技能包）。面向县处级机关及为上级代写场景。本库不是成品句库，每条只提供**逻辑骨架**，强制按「三步转化法」填入用户真实信息——启发思路，不提供成品。**v3.1 升级为 AI 协议版：字段化、可解析、可计算、可审计。**

- **68 句**，按**修辞功能**分四类：A 破题定调（7）/ B 问题剖析（10）/ C 措施执行（24）+ C2 成效印证（4）/ D 收束升华（11）+ 附录 E 固定表述（12）
- **每条六字段协议**：类｜簇｜强度｜槽位｜适用｜转化 + ✅正例/❌反例，AI 可解析生成"待填实词表"
- **三大使用定律（可判定版）**：
  - 虚实配重比（1:2，事实原子分级）：每引用一句，段内 ≥2 事实原子且 ≥1 硬事实（数字+量词/专名）
  - 语境降噪法（文种参数表）：按文种硬核程度限调用类型与强度档（S0 零引用 / S1 借壳 / S2 骨架 / S3 复制仅限 E）
  - 不可替代性检验：删掉后信息仍完整 → 自动删除
- **数据隔离（最高优先级）**：库与范例中一切数字/单位名/人名为演示数据，禁止写入用户公文；唯一合法来源是用户本轮输入的实词
- **输出审计**：引用句带 `〔#句号→实词〕` 尾注，实词来源可追溯，用户确认后剥离
- 完整范例见 `examples/`（总结 / 讲话稿 / 调研报告 / 跨文种变形）；校验脚本见 `tools/validate.js`

## 使用

作为技能：读取 `SKILL.md`，按「三步转化法」借逻辑骨架、填用户实词，遵守三大定律与数据隔离。

作为参考库：直接翻阅 `references/gems.md`，按修辞功能（定调/剖析/执行/收束）检索。

## 核心原则

- **不禁止引用，只要求转化。** 没有"绝对禁用"的句子，只有未完成转化的引用。
- **不限制数量，只规定配比。** 每处引用所在段落内 ≥2 事实原子且 ≥1 硬事实。
- **不强记文种，只训练逻辑。** 按语境判断需要哪种修辞功能，而非死记"某文种禁用某句"。
- **不挪用演示数据。** 库与范例中的数字只教学，不落公文。
- 网络流行语、抒情散文化、无信息量空排比一律不入。

## 版本历史

- **v3.1.0**：AI 协议版。gems.md 每条升级为六字段协议（类｜簇｜强度｜槽位｜适用｜转化）+ 正反例；新增簇字段（同段限 1 句）、强度档（S0–S3）、槽位语法统一（{#槽位}）；新增数据隔离声明（演示数据禁入正文）；SKILL.md 升级为可判定版（事实原子分级计数、文种参数表、输出审计双态标记、跨文种参数推演）；新增 tools/validate.js 校验脚本（序号/字段/槽位/正反例/声明 5 项检查）；主页与 README 同步更新。
- **v3.0.0**：吸收第三方建议全面重构。定位从"成品句库"改为"修辞触发器"；分类改为"按修辞功能 4 类 + 固定表述附录"；删除全部填空模板句与纯表态万能句；每条绑定适用条件+转化规则+正误示例；新增三大使用定律（虚实配重比 1:2 / 语境降噪法 / 不可替代性检验）、三步转化法、跨文种变形范例；删除固定配额与禁用场景清单；总库从 100 句压缩至 68 句。
- **v2.0.0**：按第三方实验室评估全面重构。删除 30 句滥用空句；新增半成品句式；按使用场景重组并加必替换元数据；SKILL.md 重写为强约束手册；新增 examples/；主页改随机轮换预览。
- **v1.0.0**：首版。100 句、13 分桶按文种组织、权重向高频文种倾斜。
