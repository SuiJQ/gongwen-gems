# gongwen-gems

> 🌐 项目主页：<https://suijq.github.io/gongwen-gems/>

党政公文好句库（OpenClaw 技能包）。面向县处级机关及为上级代写场景，100 句按**使用场景**组织，强约束、可落地、防空话。

- **100 句**，8 大使用场景（开头定调 7 / 问题分析 12 / 对策措施 35 / 成效展示 8 / 表态承诺 15 / 过渡衔接 9 / 结尾收束 2 / 规范用语 12）
- **每条带元数据**：场景位置 + 必替换占位符 + 频次上限
- **半成品句式**：问题导向型、措施落地型、成效数据型、表态承诺型——强制填入用户真实信息，杜绝通用废话
- **强约束使用规则**：禁止直接复制（须替换占位符并改写≥20%用词）、禁止连续使用、禁止替代事实、配额限制（≤1500字用≤2处 / 3000字内≤3处 / ≥3000字≤4处）
- 完整范例见 `examples/`（总结 / 讲话稿 / 调研报告）

## 结构

```
gongwen-gems/
├── SKILL.md              # 强约束使用手册（黑名单/步骤/正反例/配额/自检清单）
├── references/
│   └── gems.md           # 100 句完整句库（唯一数据源）
├── examples/             # 3 个正确使用完整范例
├── index.html            # 项目主页（句库随机轮换预览）
└── LICENSE               # CC BY-NC-SA 4.0
```

## 使用

作为技能：读取 `SKILL.md`（强约束手册），按使用场景选句，替换 `{占位符}`，改写至少 20% 用词，遵守配额。

作为参考库：直接翻阅 `references/gems.md`，按场景标签检索。

## 核心规则

- 一句一意，宁缺毋滥，一段材料点睛 1-2 处即可
- 用户未提供具体数据/案例时，不得使用本库句子
- 网络流行语、抒情散文化、无信息量空排比一律不入

## 版本历史
