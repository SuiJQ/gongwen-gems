# gongwen-gems

> 🌐 项目主页：<https://suijq.github.io/gongwen-gems/>

党政公文好句库（OpenClaw 技能包）。面向县处级机关及为上级代写场景，100 句严肃、庄重、有信息量的公文好句，按 22 种公文题材（15 法定 + 7 事务）分桶，权重向高频文种倾斜。

- **100 句**，编号连续，风格统一（机关书面语严肃风格）
- **13 个分桶**：讲话稿 20 / 总结·工作报告 12 / 汇报 10 / 经验交流·典型 10 / 调研 8 / 请示·报告 6 / 述职 5 / 通知·通报·意见 5 / 简报 5 / 计划方案 5 / 决定·决议 5 / 会议纪要 4 / 低频文种通用 5
- 排比、对仗、四字格、数字结构都收——**被用滥了才叫套话**；网络流行语、口语化、抒情散文化表达一律不入
- 每条统一格式：`序号. 句子 —— 适用场景`，可直接嵌入材料

## 使用

作为技能：读取 `SKILL.md`，按 22 种文种定位分桶，在 `references/gems.md` 中取句。

作为参考库：直接翻阅 `references/gems.md`，按场景标签检索。

## 结构

```
gongwen-gems/
├── SKILL.md              # 技能说明（description 贴近真实触发场景）
├── references/
│   └── gems.md           # 100 句完整句库（唯一数据源）
└── index.html            # 项目主页
```

## 选句原则

- **一句一意**：每句只承担一个表达功能（定调、鼓劲、表态、收束……）
- **严肃优先**：拿不准时选更庄重的表达
- **宁缺毋滥**：一段材料用 1-2 句点睛即可，不硬塞

## 版本历史

- **v1.0.0**：首版。100 句入库，13 分桶按处级高频文种权重倾斜；描述贴近真实触发场景（写总结/讲话/汇报/述职/事迹材料需要句子点睛时使用）。
