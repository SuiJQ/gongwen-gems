# gongwen-gems

> 🌐 项目主页：<https://suijq.github.io/gongwen-gems/>

党政公文**修辞触发器**库（OpenClaw 技能包）。面向县处级机关及为上级代写场景。本库不是成品句库，每条只提供**逻辑骨架**，强制按「三步转化法」填入用户真实信息——启发思路，不提供成品。

- **68 句**，按**修辞功能**分四类：A 破题定调（7）/ B 问题剖析（10）/ C 措施执行（24）+ C2 成效印证（4）/ D 收束升华（11）+ 附录 E 固定表述（12）
- **每条绑定元数据**：适用条件 + 虚实转化规则 + 正误示例
- **三大使用定律**：虚实配重比（1:2，每处引用所在段内至少 2 处事实）/ 语境降噪法（按文种硬核程度限调用类型）/ 不可替代性检验（删掉后信息仍完整 → 自动删除）
- **三步转化法**：提实料 → 定向借壳 → 重组血肉，不通则放弃
- 完整范例见 `examples/`（总结 / 讲话稿 / 调研报告 / 跨文种变形）

## 结构

```
gongwen-gems/
```

## 使用

作为技能：读取 `SKILL.md`，按「三步转化法」借逻辑骨架、填用户实词，遵守三大定律。

作为参考库：直接翻阅 `references/gems.md`，按修辞功能（定调/剖析/执行/收束）检索。

## 核心原则

- **不禁止引用，只要求转化。** 没有"绝对禁用"的句子，只有未完成转化的引用。
- **不限制数量，只规定配比。** 每处引用所在段落内至少 2 处具体事实。
- **不强记文种，只训练逻辑。** 按语境判断需要哪种修辞功能，而非死记"某文种禁用某句"。
- 网络流行语、抒情散文化、无信息量空排比一律不入。
