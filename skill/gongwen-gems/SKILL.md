# 使用协议

## 数据入口（唯一）

句库：`references/gems.md`，共 71 句。
**一切金句只能出自该文件**——禁止凭记忆引用、禁止仿写"听起来像"的句子。
库中数字、单位名、人名为**演示数据**，禁止写入用户公文。

## 取句

优先运行脚本（确定性取句，杜绝编造）：

```
python3 scripts/pick.py --class C --strength S1,S2 --exclude-cluster C-清单 --count 2
```

无脚本环境时手工筛选：
1. 按文种与段落位置定类：A 破题定调 / B 问题剖析 / C 措施执行 / C2 成效印证 / D 收束升华 / E 固定表述
2. 强度 S1/S2 优先于 S3；同簇同段限 1 句（E 类固定表述豁免）；一篇用几句由调用方决定，本技能不预设数量限制
3. 所有 `{#槽位}` 必须用**用户本轮输入中出现过的实词**填实；填不满 → 放弃该句，换一句或不用
4. 引用句须改写 ≥20% 或仅借逻辑骨架（E 类 S3 直接使用合法），保证与上下文衔接

## 安全不变量（违反即失败）

- 禁止虚构数据：数字、成效、案例只能来自用户输入
- 禁止留空占位符
- 禁止连续堆砌金句：金句之间必须有实词内容间隔，不得金句串
- 禁止把正反例（✅/❌）中的演示内容写进正文

## 输出前自检

□ 金句全部出自 gems.md　□ 槽位全部填实　□ 无演示数据混入　□ 无同簇连用　□ 未连续堆砌

## 边界

- 不决定文种结构、篇幅、配比——由调用方（工作流/专家团/用户）决定
- 不承担角色人设（"资深笔杆子"等）——由专家配置决定
- 不整篇代写范文，除非用户明确要求
